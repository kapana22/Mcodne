# Archive — finished audits, kept for their reasoning only

Nothing here is current and nothing links to it. These are dated audits whose
findings were acted on; they are kept because the ARGUMENT in them is sometimes
worth re-reading, not because any of it still describes the site.

**Never reason from a number in this folder.** Re-measure — `npm run map`, a
`count()`, `ls`. The rules that survived these audits live in `../../CLAUDE.md`;
the reasoning behind them lives in `../product-model.md` and
`../design-system.md`.
