## 7. ახალი ზედაპირის წესები (checklist)

1. **ჯერ პრიმიტივი:** `<Container>` → `<PageHeader>`/`<Eyebrow>` → `<Card>` → `<Btn>` → `<EmptyState>`.
   ხელით shell მხოლოდ მაშინ, როცა პრიმიტივი ობიექტურად ვერ ფარავს — და მაშინ ტოკენებით.
2. **ფერი** — მხოლოდ ტოკენი; hex გვერდზე = ბაგი. ლურჯი აქცენტად — არა.
3. **ტექსტი** — მხოლოდ კიბიდან (`text-body` default); `text-[Npx]` მხოლოდ კომენტარიანი off-ramp.
4. **მოძრაობა** — `transition-*`-ს ახლდეს duration-ტოკენი; `animate-*`-ს — `motion-safe:`;
   ახალი keyframe არ ემატება (ბიბლიოთეკა დახურულია).
   ⚠️ 2026-09-03-ს ეს წესი ერთი დღით შევასუსტე — `shimmer` მეორედ დავარეგისტრირე
   როგორც `progress-sweep` (ერთხელ, 900ms), intake-ის ზოლზე გასარბენად. მეორე
   დღეს ორივე წაიშალა: მფლობელმა თქვა „არაპროფესიონალურია, საიტს არ უხდება" —
   და მართალი იყო. **წესი ძალაშია და გამონაკლისი აღარაა.** ისტორია აქ იმიტომ
   რჩება, რომ იგივე იდეა ხელახლა არ მოვიდეს: მოძრავი ნათება ზოლზე ნიშნავს
   „იტვირთება", ეს ზოლი კი ადგილს აჩვენებს — ანიმაცია მნიშვნელობას ეწინააღმდეგება.
5. **სიმაღლეები** — კონტროლები h-9/h-11/h-12; ყველაფერი დაჭერადი ≥40px.
